Открывайте **эту папку** в Android Studio. Модули: `app`, `thread`, `data_thread`, `looper`, `CryptoLoader`, `ServiceApp`, `WorkManager`, `MireaProject`. UITests — отдельный тестовый APK, не упражнение. Общая проверка: `Verify Lesson4`; проверка на AVD: `Device Tests Lesson4`.

SDK/эмулятор/загруженные Gradle-зависимости остаются установленными. local.properties указывает локальный SDK. Точные версии и фактическая проверка приведены в отчёте.

## Личный выбор пользователя

Сериал — **«Лучше звоните Солу»**, выбран в ответе пользователя. В thread поле movie заполнено при первом создании Activity. Обработчик rename читает текущий текст и включает его в имя главного потока вместе с группой/номером. При повороте ввод восстанавливается Android по ID; начальное значение не запрещает редактирование. В тесте проверяется и исходное название, и новое имя потока.
