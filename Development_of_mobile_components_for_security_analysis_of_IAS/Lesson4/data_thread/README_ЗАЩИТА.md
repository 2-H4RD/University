# data_thread · практика 4

**Требование:** runOnUiThread, post, postDelayed; описание различий и последовательности в TextView.

Нажмите запуск и дождитесь журнала runn1 → runn2 → runn3. begin — монотонное время elapsedRealtime, а не часы календаря. В Executor происходит ожидание 2000 мс, затем ui(runn1), ещё 1000 мс, postDelayed(runn3,2000) и post(runn2). runn2 оказывается готов раньше отложенного runn3. runOnUiThread из фонового потока ставит действие в главную очередь, а из главного может исполнить сразу. View.post всегда планирует Runnable через очередь View; postDelayed задаёт минимальный срок, но загрузка главного потока способна отодвинуть исполнение. running и отключение кнопки предотвращают смешивание нескольких журналов. Спите только в фоне: Thread.sleep в UI остановил бы кнопки и перерисовку.
