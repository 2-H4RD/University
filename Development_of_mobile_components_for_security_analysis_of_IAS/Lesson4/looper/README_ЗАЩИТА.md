# looper · практика 4

**Требование:** Возраст/профессия → Message/Bundle → Handler/Looper; возраст задаёт задержку; Log.d.

Введите возраст 1 и профессию, нажмите передачу. MyLooper — собственный Thread. run вызывает Looper.prepare, создаёт Handler для собственной MessageQueue, затем Looper.loop. volatile handler делает ссылку видимой между потоками, ready включает кнопку только после инициализации. AGE и JOB — ключи Bundle, возраст превращается в миллисекунды age*1000L. sendMessageDelayed планирует сообщение без блокировки UI. Handler рабочего потока формирует строку и пишет Log.d с тегом MyLooper; ответный Handler привязан к main Looper и обновляет TextView. Ввод ограничен 0–120 для разумной демонстрации. onDestroy вызывает quitSafely и очищает callbacks главного Handler. Продемонстрируйте пустую профессию и недопустимый возраст.
