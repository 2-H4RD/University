# app · практика 4

**Требование:** Плеер с ViewBinding в портретной и альбомной ориентации.

Откройте app и найдите activity_main.xml и альтернативу layout-land/activity_main.xml. Одинаковые ID дают один тип ActivityMainBinding в обеих ориентациях. Нажмите воспроизведение, затем паузу и стоп; поверните устройство. В onCreate объект binding получает реальные View выбранной конфигурации. player — ссылка MediaPlayer, position — позиция в миллисекундах. При первом нажатии MediaPlayer.create читает R.raw.signal; seekTo восстанавливает позицию. isPlaying выбирает pause либо start. Стоп освобождает проигрыватель через release и обнуляет позицию. onSaveInstanceState переносит позицию в Bundle; onPause приостанавливает звук; onDestroy освобождает объект. Встроенная мелодия «Сигнал безопасного канала» создана для упражнения, а не названа чужим произведением. Обычная Activity не должна продолжать звук в фоне: для этого следующий модуль ServiceApp.
