# MireaProject · практика 4

**Требование:** Отдельный фрагмент фоновой задачи через Worker либо Service.

Откройте меню → «Фоновая задача». BackgroundFragment создаёт поле auditText и наблюдает mirea-audit через getViewLifecycleOwner. Это важно: View фрагмента живёт меньше Activity и подписка не должна обновлять уничтоженное представление. Кнопка запуска создаёт настоящий UploadWorker; WorkManager хранит задачу независимо от текущего экрана. Перейдите на другой экран и вернитесь: состояние читается из WorkInfo. Запустите abc и объясните, что SHA-256 проверяет целостность, но не скрывает исходный текст. Класс LabFragment централизует создание элементов и безопасную доставку UI-результата.
