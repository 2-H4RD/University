## Где и как проверялось

Итоговая установка и сверка APK обновлены **24.10.2026**. Инструментальные сценарии выполнены 23.10.2026; точное время сохранено в исходном JUnit XML.

Сборка, статические проверки и запуск AndroidJUnitRunner выполнялись в открытом проекте **Android Studio**, через конфигурации Verify Lesson4 и Device Tests Lesson4. Исходники исправлялись встроенным редактором/инструментами IDE. SDK adb использован для подготовки GPS AVD, чтения диагностик и экспорта уже созданных Android-файлов/доказательств.

Среда: Android Studio 2026.2.1, build 262.9437.185.2621.16467767; встроенная JVM OpenJDK 25.0.3. Gradle Wrapper 9.6.0, Android Gradle Plugin 9.4.1; compileSdk/targetSdk 35, minSdk 26, исходный Java 11. Устройство Pixel_9, Android 15/API 35 x86_64 Google Play, WHPX, serial emulator-5554. ## Что исправлено при проверке

- Исправлена инфраструктура доказательств: target context вместо каталога test APK, копирование до удаления target приложения AGP.
- Тест разрешает настоящий launcher через PackageManager; категория LAUNCHER не подменяется DEFAULT.
- Учтено преобразование стандартных Button в верхний регистр при проверке фонового фрагмента. Это исправления селекторов тестов, не отмена предметных assertions.

## Ограничения и оставшиеся действия

По ответу пользователя сериал — «Лучше звоните Солу»; в практике 6 поэт — Пушкин Александр Сергеевич. Личные значения внесены в начальные поля и проверены в Android Studio. Другой собственный сохранённый ввод не удаляется; предыдущие технические заглушки распознаются отдельно.

Проверена одна установленная версия Android и один AVD. SDK, AVD, wrapper и загруженные зависимости сохранены. AGP после connected-теста удаляет target/test APK; конфигурация Install Lesson4 устанавливает приложения заново без тестового cleanup. У MireaProject работ 7 и 8 общий applicationId, поэтому последняя версия заменяет предыдущую; исходные снимки и APK обеих работ остаются.

## Повторение

Откройте эту папку в Android Studio, Sync → Verify Lesson4 → запустите Pixel_9 → Device Tests Lesson4. Для Lesson8 передайте GPS в Extended Controls → Location. Не запускайте несколько UI-наборов на одном AVD одновременно. После тестов выберите Install Lesson4. Изменение личных конфигураций требует пересборки и отдельной проверки облака/MapKit по инструкции.
