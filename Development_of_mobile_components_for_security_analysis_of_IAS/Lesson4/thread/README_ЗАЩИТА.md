# thread · практика 4

**Требование:** Ввод числа пар/дней, среднее в Thread, имя главного потока с группой/номером/фильмом, Logcat.

Введите 60 пар и 20 учебных дней: ожидается 3.00 пар/день с учётом десятичного разделителя локали. Введите фильм и переименуйте главный поток. Покажите исходное и новое имя в threadInfo. Слушатель кнопки работает в UI: он читает EditText и проверяет total ≥ 0, days > 0. counter — AtomicInteger, увеличивающий номер запуска. В new Thread создаётся отдельный поток с именем Lesson4-calculation-N; приведение total к double предотвращает целочисленное деление. ui(...) возвращает изменение TextView на главный поток. В Logcat фильтруйте ThreadProject: видны начало, завершение и average. Нулевые дни отклоняются до создания Thread. Переименование потока не создаёт новый поток и не меняет его приоритет. Покажите повторный запуск и отсутствие деления на ноль.

## Личный выбор пользователя

Сериал — **«Лучше звоните Солу»**, выбран в ответе пользователя. В thread поле movie заполнено при первом создании Activity. Обработчик rename читает текущий текст и включает его в имя главного потока вместе с группой/номером. При повороте ввод восстанавливается Android по ID; начальное значение не запрещает редактирование. В тесте проверяется и исходное название, и новое имя потока.
