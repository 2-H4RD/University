# YandexDriver · практика 8

**Требование:** Несколько вариантов маршрута от устройства до любимого заведения, GPS эмулятора, маркер с краткой информацией.

Начальная точка — последняя позиция устройства, конечная — выбранное заведение. Учебное заведение помечено как пример; свою точку можно ввести в полях. DrivingRouter COMBINED создаётся через DirectionsFactory, DrivingOptions запрашивает до трёх маршрутов. requestRoutes возвращает DrivingSession, listener получает настоящие DrivingRoute или ошибку. Каждый route.geometry рисуется своей Polyline, подпись содержит расстояние/время из metadata. Несколько вариантов возможны только если сервис их нашёл; код не выдумывает альтернативу прямым отрезком. Маркер назначения хранит описание и открывает диалог. Listener и session удерживаются полями; при повторном запросе старый session отменяется. Путь проверить можно только с действующим API ключом и сетью.
