# MireaProject · практика 8

**Требование:** Фрагмент заведений, список/описания/карта; маркер показывает адрес+описание; дополнительная функция карты.

«Заведения» связывает список карточек и OSM карту. Встроенные точки — МИРЭА, парк Горького и Воробьёвы горы — явно учебные примеры. Нажатие карточки выбирает точку на карте, нажатие маркера показывает адрес и описание. Формой можно добавить собственное место с координатами и сохранить его в Preferences; проверяются пустые значения и диапазоны широты/долготы. Дополнительная функция fit bounds охватывает все точки, расстояние от устройства подписано как расстояние по прямой. Оно вычисляется отдельно от дорожного маршрута и не подменяет его. Для наследуемого Firebase-входа требуется собственный JSON либо явный локальный Auth Emulator; интеграции карты и входа имеют разные настройки.
