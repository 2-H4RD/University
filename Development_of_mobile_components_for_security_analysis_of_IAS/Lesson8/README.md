# Практическая работа №8

[Оригинал задания PDF](Практика%20№%208.pdf) · [Требования по каждому упражнению](ТРЕБОВАНИЯ.md) · [Инструкция по защите](ИНСТРУКЦИЯ_ПО_ЗАЩИТЕ.md) · [Подробный разбор всего кода](РАЗБОР_КОДА.md) · [Отчёт о проверках](ОТЧЁТ_О_ПРОВЕРКАХ.md)

Открывайте **эту папку** в Android Studio. Модули: `YandexMaps`, `YandexDriver`, `OSMMaps`, `MireaProject`. UITests — отдельный тестовый APK, не упражнение. Общая проверка: `Verify Lesson8`; проверка на AVD: `Device Tests Lesson8`.

SDK/эмулятор/загруженные Gradle-зависимости остаются установленными. local.properties указывает локальный SDK. Точные версии и фактическая проверка приведены в отчёте.

Сначала прочитайте [подключение сервисов](ПОДКЛЮЧЕНИЕ_СЕРВИСОВ.md). Облачные операции требуют ваших настроек; сообщения об их отсутствии не считаются успешной проверкой сервиса.
