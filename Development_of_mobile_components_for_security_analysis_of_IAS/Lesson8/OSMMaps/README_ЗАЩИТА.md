# OSMMaps · практика 8

**Требование:** osmdroid: тайлы, масштаб/жесты, камера, location, compass/rotation/scale, интересные места с описанием; два пункта/маршруты из условия раздела.

Карта загружает тайлы OpenStreetMap через osmdroid. Начальную камеру задают `setZoom` и `setCenter`. Масштаб меняется кнопками и жестами. `MyLocationNewOverlay` получает координаты устройства, `CompassOverlay` показывает направление, `RotationGestureOverlay` поворачивает карту, `ScaleBarOverlay` рисует шкалу. При обычном нажатии на маркер открывается название и описание места.

1. Нажмите **«Выбрать старт»** и удерживайте нужную точку на карте. Повторите для **«Выбрать финиш»**. Под кнопками появятся координаты A и B, а на карте — соответствующие маркеры.
2. Нажмите **«Построить маршруты»**. Приложение отправит обе точки в OSRM и нарисует полученные варианты разными цветами. Камера охватит все варианты. Сервис может вернуть один маршрут, даже если приложение запросило альтернативы.
3. Для проверки GPS откройте модуль без ручного выбора, нажмите **«Моё местоположение»**, передайте учебную точку в эмуляторе и постройте маршрут до Парка Горького. Если выбрана только одна ручная точка, второй остаётся GPS для старта или парк для финиша.

В коде `selection` показывает, какой маркер устанавливает очередное долгое нажатие. `routeStart` и `routeEnd` хранят маркеры с координатами, а `onSaveInstanceState` сохраняет координаты при повороте. В `loadRoutes` значения из `GeoPoint` передаются в порядке «долгота, широта». Ответ GeoJSON преобразуется обратно в пары «широта, долгота», из которых `Polyline` рисует дорожную геометрию. Если запрос завершится ошибкой, на экране появится сообщение сервиса.
