# InternalFileStorage · практика 6

**Требование:** Поле/кнопка, памятная дата России с описанием во внутреннем UTF-8 файле; экспорт в raw.

Исходный пример даты — 12 апреля 1961, полёт Гагарина. Нажатие save читает текст, openFileOutput("history.txt",MODE_PRIVATE) создаёт или перезаписывает приватный файл, UTF-8 сохраняет кириллицу. try-with-resources закрывает поток даже при ошибке. load читает байтовым буфером в ByteArrayOutputStream и декодирует UTF-8. Файловые операции идут в io; TextView меняется через ui. Сохраните, испортите поле вручную, загрузите: вернётся текст файла. В Device Explorer /data/data/<id>/files/history.txt экспортируйте фактический файл и сравните с InternalFileStorage/src/main/res/raw/history.txt. Ресурс raw — копия для сдачи, приложение не пишет в APK.
