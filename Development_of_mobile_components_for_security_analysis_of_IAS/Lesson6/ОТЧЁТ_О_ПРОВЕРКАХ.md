## EmployeeDB — ручной ID и сброс базы, 07.11.2026

По запросу пользователя ID вводится вручную. Автогенерация в Entity отключена. Пустое поле, буквы/дроби/переполнение long, ноль/отрицательное значение и занятый ID получают отдельные сообщения. Для дубликата существующая запись сохраняется. После удаления ID можно использовать снова.

Версия схемы увеличена до 2. Миграция RESET_1_2 однократно очищает старую таблицу версии 1 по явному запросу пользователя. Последующие запуски версии 2 сохраняют новые записи.

Lint Error/Fatal — 0, предупреждений — 23. Общий набор из шести сценариев ниже относится к первоначальной проверке 23.10.2026. ## Ограничения и оставшиеся действия

По ответу пользователя сериал — «Лучше звоните Солу»; в практике 6 поэт — Пушкин Александр Сергеевич. Личные значения внесены в начальные поля и проверены в Android Studio. Другой собственный сохранённый ввод не удаляется; предыдущие технические заглушки распознаются отдельно.

Проверена одна установленная версия Android и один AVD. SDK, AVD, wrapper и загруженные зависимости сохранены. AGP после connected-теста удаляет target/test APK; конфигурация Install Lesson6 устанавливает приложения заново без тестового cleanup. У MireaProject работ 7 и 8 общий applicationId, поэтому последняя версия заменяет предыдущую; исходные снимки и APK обеих работ остаются.
