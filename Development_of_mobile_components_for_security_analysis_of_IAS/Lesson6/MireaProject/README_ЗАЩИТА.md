# MireaProject · практика 6

**Требование:** Профиль SharedPreferences; файловый фрагмент с обработкой; FAB открывает диалог создания записи.

«Профиль» восстанавливает имя/группу/роль из SharedPreferences и сохраняет их после валидации. «Файловая лаборатория» содержит настоящий FloatingActionButton с описанием «Создать запись». Он открывает CreateNoteDialog как DialogFragment. Положительная кнопка переопределена после show, поэтому ошибка имени/пустого текста не закрывает диалог. Результат передаётся FragmentResult под new-note, FileLabFragment пишет приватный текстовый файл: исходный текст, Base64 и SHA-256. Base64 — обратимое кодирование байтов, SHA-256 — односторонний хеш; ни одно не является шифрованием. Покажите отмену диалога, ошибку имени, успешное создание и обновление списка; найдите файл в Device Explorer.
