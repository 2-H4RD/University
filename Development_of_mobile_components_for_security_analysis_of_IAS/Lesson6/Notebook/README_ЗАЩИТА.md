# Notebook · практика 6

**Требование:** Имя+цитата, сохранение с перезаписью и загрузка из публичного Documents; два файла с цитатами, экспорт в raw.

Нажмите выбор папки и разрешите именно публичную Documents через системный Storage Access Framework. Проверяется tree document ID primary:Documents, чтобы не принять другую папку за выполнение условия. takePersistableUriPermission сохраняет доступ; дерево tree и его строка в Preferences восстанавливаются при новом запуске. fileOperation проверяет имя .txt без путей, непустую цитату и наличие tree. DocumentFile.findFile ищет существующий файл; createFile нужен только при отсутствии. openOutputStream(uri,"wt") перезаписывает и усекает хвост старого текста. load читает content Uri через ContentResolver. Создайте две разные цитаты, затем замените длинную первой короткой и загрузите: хвоста быть не должно. Экспортируйте оба настоящих Documents/*.txt в Notebook/src/main/res/raw. Разрешение MANAGE_EXTERNAL_STORAGE не требуется и не используется.
