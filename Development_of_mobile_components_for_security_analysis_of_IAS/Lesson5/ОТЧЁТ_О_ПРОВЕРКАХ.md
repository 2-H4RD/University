## Где и как проверялось

Сборка, статические проверки и запуск AndroidJUnitRunner выполнялись в открытом проекте **Android Studio**, через конфигурации Verify Lesson5 и Device Tests Lesson5. Исходники исправлялись встроенным редактором/инструментами IDE. SDK adb использован для подготовки GPS AVD, чтения диагностик и экспорта уже созданных Android-файлов/доказательств.

Среда: Android Studio 2026.2.1, build 262.9437.185.2621.16467767; встроенная JVM OpenJDK 25.0.3. Gradle Wrapper 9.6.0, Android Gradle Plugin 9.4.1; compileSdk/targetSdk 35, minSdk 26, исходный Java 11. Устройство Pixel_9, Android 15/API 35 x86_64 Google Play, WHPX, serial emulator-5554. Platform Tools 37.0.1.

Verify выполняет assembleDebug, lintDebug и testDebugUnitTest. Device Tests выполняет installDebug и :UITests:connectedDebugAndroidTest. JVM-задачи NO-SOURCE не объявляются успешно выполненными тестами приложения. Доказательством предметного поведения являются приведённые ниже Android assertions и реальные снимки.

## Что исправлено при проверке

- В MireaProject добавлен uses-feature camera required=false: разрешение CAMERA больше не вызывает ошибку совместимости Android Lint.
- Проверка камеры учитывает прокрутку, поворот и возвращение в портрет; шторка закрывается перед тестом.
- Для непрерывно меняющихся датчиков настроено ожидание UI idle 1 с; фактические результаты по-прежнему ждут Until/assertions с отдельными таймаутами.

## Ограничения и оставшиеся действия

Проверка выполнена на виртуальной камере/датчиках/аудиовводе AVD. Она подтверждает Android API и реальные файлы, но не оценивает качество камеры или распознавание речи физического телефона.

Проверена одна установленная версия Android и один AVD. SDK, AVD, wrapper и загруженные зависимости сохранены. AGP после connected-теста удаляет target/test APK; конфигурация Install Lesson5 устанавливает приложения заново без тестового cleanup. У MireaProject работ 7 и 8 общий applicationId, поэтому последняя версия заменяет предыдущую; исходные снимки и APK обеих работ остаются.

## Повторение

Откройте эту папку в Android Studio, Sync → Verify Lesson5 → запустите Pixel_9 → Device Tests Lesson5. Для Lesson8 передайте GPS в Extended Controls → Location. Не запускайте несколько UI-наборов на одном AVD одновременно. После тестов выберите Install Lesson5. Изменение личных конфигураций требует пересборки и отдельной проверки облака/MapKit по инструкции.
