# MireaProject · практика 5

**Требование:** Логическая задача датчика, творческий результат камеры, полезное применение микрофона, запросы разрешений.

Меню «Аппаратная часть» объединяет полезные сценарии. HardwareFragment использует XYZ как уровень телефона: перед съёмкой документа видно отклонение. «Фотофиксация инцидента» открывает PhotoNoteActivity: полноценное фото плюс caption, сохранённое через Preferences. «Голосовая заметка» открывает VoiceNoteActivity: запись плюс текстовое описание. Это предметное применение трёх компонентов, а не только копия демонстрационных экранов. Проследите переход Intent → отдельная Activity и наследование общей BaseActivity. Покажите сохранение описания после возврата и новую запись без одновременного player/recorder. Разрешения CAMERA и RECORD_AUDIO не следует заменять разрешением доступа ко всем файлам.
