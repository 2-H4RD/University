# Accelerometer · практика 5

**Требование:** Текущие XYZ ускорения, SensorEventListener, регистрация onResume/отмена onPause.

Откройте Extended Controls эмулятора → Virtual sensors и измените положение. X/Y/Z в м/с² должны меняться, включая составляющую земного притяжения. manager — SensorManager, sensor — акселерометр; при его отсутствии показано сообщение. onResume регистрирует this как SensorEventListener с SENSOR_DELAY_UI; onPause снимает подписку для экономии ресурсов и отсутствия скрытых обновлений. event.values[0..2] — три оси системы координат устройства, не GPS. String.format задаёт три десятичных знака, status подтверждает полученный SensorEvent. onAccuracyChanged оставлен как обязательный callback интерфейса; пустое тело означает, что отдельный UI точности не нужен.
