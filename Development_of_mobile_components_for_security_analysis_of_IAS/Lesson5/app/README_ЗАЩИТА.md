# app · практика 5

**Требование:** SensorManager.getSensorList(TYPE_ALL), список названий/диапазонов датчиков.

SensorManager запрашивается системным сервисом, getSensorList(TYPE_ALL) возвращает реальные доступные датчики конкретного устройства. Цикл формирует для каждого Map с name/detail, где detail включает type, maximumRange и vendor. SimpleAdapter связывает эти ключи с двумя TextView стандартной строки ListView. summary показывает количество. Это список возможностей, а не поток измерений. Пустой список на оборудовании без датчиков допустим; на выбранном AVD должны быть реальные строки. Объясните отличие списка всех сенсоров от getDefaultSensor(TYPE_ACCELEROMETER).
