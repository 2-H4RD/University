Открывайте **эту папку** в Android Studio. Модули: `app`, `Accelerometer`, `Camera`, `AudioRecord`, `MireaProject`. UITests — отдельный тестовый APK, не упражнение. Общая проверка: `Verify Lesson5`; проверка на AVD: `Device Tests Lesson5`.

SDK/эмулятор/загруженные Gradle-зависимости остаются установленными. local.properties указывает локальный SDK. Точные версии и фактическая проверка приведены в отчёте.
