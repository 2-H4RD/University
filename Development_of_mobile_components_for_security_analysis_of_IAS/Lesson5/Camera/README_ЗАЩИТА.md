# Camera · практика 5

**Требование:** Запрос разрешения, системная камера, FileProvider/EXTRA_OUTPUT, файл в папке приложения и ImageView, Binding.

Нажмите фотографирование и ответьте на runtime запрос камеры. FileProvider превращает файл Pictures/photo_*.jpg в content Uri с ограниченной выдачей прав. authorities использует applicationId, а xml/paths разрешает только Pictures, не весь диск. TakePicture передаёт этот Uri системному приложению как EXTRA_OUTPUT: результатом является boolean, а оригинал лежит в файле. pendingPath относится к текущей съёмке, photoPath — к последнему успешному снимку; отмена не заменяет успешное фото. showPhoto сначала читает только размеры BitmapFactory.Options.inJustDecodeBounds, затем декодирует уменьшенное превью с inSampleSize для памяти. В status остаются размеры оригинала и путь. Перезапустите и поверните экран; выбранный путь хранится в Preferences и Bundle. Сравните оригинал JPEG в Device Explorer и превью ImageView; это разные размеры данных.
