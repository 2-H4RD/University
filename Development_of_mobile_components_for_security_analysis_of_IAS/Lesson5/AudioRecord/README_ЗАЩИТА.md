# AudioRecord · практика 5

**Требование:** MediaRecorder и MediaPlayer, запись/воспроизведение, взаимное исключение кнопок, №/группа на записи.

Кнопка записи содержит номер 5 и группу БИСО-02-22. Разрешение RECORD_AUDIO запрашивается только при записи. recordFile — Music/voice_note.3gp в каталоге приложения; recorder пишет MIC → THREE_GPP → AMR_NB. prepare настраивает кодек/файл, start начинает захват. recording/playing описывают взаимоисключающие состояния, updateButtons запрещает проигрывание во время записи и запись во время воспроизведения. stopRecording обрабатывает слишком короткую запись: stop может бросить RuntimeException, тогда повреждённый файл удаляется. player читает готовый файл; completion освобождает его и возвращает кнопки. onStop завершает запись и проигрывание. Сделайте запись длиннее секунды, воспроизведите, покажите реальный размер 3GP в Device Explorer. Не выдавайте тишину виртуального микрофона за проверку качества речи физического устройства.
